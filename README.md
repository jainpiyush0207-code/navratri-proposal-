# Navratri Proposal Site

A mobile-first interactive mini-site for GitHub Pages.

## Files

- `index.html` — all screens/content
- `style.css` — cinematic visual design + responsive layout
- `script.js` — screen transitions, buttons, petals and proposal flow
- `assets/bouquet-man.png` — generated hero image

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload all files while keeping the `assets` folder intact.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select the `main` branch and `/root` (the repository root).
6. Save and wait for GitHub Pages to publish.

The site is static, so no database or backend is required.
